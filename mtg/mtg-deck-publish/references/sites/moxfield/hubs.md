# Choosing hubs

**Hubs** are the public chips under a deck's name (`AGGRO`, `ARTIFACTS`,
`DIMIR (UB)`, `TEMPO`): chosen from a fixed list, visible to everyone, and the main
way strangers find the deck. Moxfield's own modal calls them *themes*, so the two
words mean the same thing. This file is about **which** hubs to pick;
`references/sites/moxfield/operations.md` covers how to set them, and how folders work.

Hubs are not the user's private filing - that is **folders**, on `/decks/personal`.
Moxfield has no third thing called "labels" or "tags" at the deck level, so if that
word comes up it means hubs when the context is publishing and folders when the
context is filing - worth one clarifying line rather than guessing.

## The test

Hubs are a discovery mechanism, so the test for each one is: **would someone
browsing that hub be glad to find this deck?** Three to six well-chosen hubs beat
ten loosely-related ones - a deck tagged with everything ranks as noise, and it
irritates the people browsing.

Cover these angles, in roughly this priority:

1. **Colour identity** - one hub, the guild/shard/wedge name or the mono colour.
2. **Playstyle** (e.g., Aggro, Control, Combo, Midrange, Tempo, Stax, Prison,
   etc.) - pick the one that describes how the deck actually wins, not how it
   feels.
3. **Mechanical theme** - the engine a searcher would look for (e.g., Artifacts,
   Aristocrats, Tokens, Reanimator, Lands Matter, +1/+1 Counters, etc.).
4. **Context**, only if true (e.g., Budget, cEDH, Competitive, Casual, Modified,
   Webcam Friendly, etc.).

`Unmaintained` and `Help Wanted` are the user's to ask for, not yours to add -
they are statements about the deck's upkeep that only the user can make.

`Primer` is different: it is a factual statement about the deck, and it is what
makes the deck findable by people browsing for decks that have one. **Stage it
whenever you are publishing a primer with real content** - in the ledger, through
the gate, like every other hub. Forgetting it wastes the work.

The list below is fixed - you cannot create a hub. If a concept has no hub, search
the *Select Themes* modal to be sure, then let it go; do not approximate with an
unrelated hub. Moxfield adds hubs over time, so treat the modal as authoritative
and this list as the working copy.

## Worked example

A Pioneer Dimir artifact deck that animates cheap indestructible artifacts and
wins on turn four while holding up interaction:

`Dimir (UB)` (colour) + `Tempo` (how it wins) + `Artifacts` (the engine) +
`Affinity` (the recognisable archetype name). Four hubs, each one a shelf a real
person browses.

Not: `Aggro` *and* `Tempo` *and* `Midrange` - pick the true one. Not `Budget`
unless the deck actually is.
